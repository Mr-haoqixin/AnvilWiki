## Use the Green Gem

Player feedback points **Green Gem** at the left statue in the common room. If the item does not trigger an effect, first confirm you have selected the correct item and interact with the statue.

## Distinguish from the Stuck Report

The original page also records a case where character movement and menu froze after a use event. This is a single anomaly report, not representative that every normal use causes a stuck state; if a freeze occurs, first preserve the save state and check the latest fix info.
