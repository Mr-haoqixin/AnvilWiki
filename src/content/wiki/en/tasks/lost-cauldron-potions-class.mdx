## Compare Demo Patches

First confirm the current demo version, then compare the **0.465** and **0.466** official patch notes separately. Fix contents of different versions should not be conflated; update to the available version first and recheck the potions class state.

## Do Not Try Unconfirmed Restore Commands

The original page did not confirm an item command that directly restores the cauldron. If the class is still stuck, check the dated saves provided by the game and roll back carefully; back up the current save before rolling back to avoid overwriting unique progress.
