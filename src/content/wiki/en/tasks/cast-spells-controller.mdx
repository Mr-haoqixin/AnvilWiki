## Player-Reported Cast Order

Select the song to use in the spell book and press **X** to pin it; press **RT** to start the instrument prompt, press **A** to spend mana, and finally press **X** to complete playing.

## Do Not Treat as a Universal Key Table

These keys come from a demo player report, not an official description for all controller layouts. If the game shows different prompts, prioritize operating by the current device and custom control settings.
