## Update to Version 1.02

**Version 1.02** fixes the issue where player-placed **Cobblestone Paths** disappear. When this happens, first check the game version and update, then observe newly laid paths.

## Distinguish Old Version Advice

Old-version players tried redrawing paths as a temporary workaround; this is not an official fix. The **Version 1.01** change to Pickaxe is a separate adjustment, do not conflate it with the cause of path disappearance.
