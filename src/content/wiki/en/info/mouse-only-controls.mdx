## Click-to-Interact Is Not Free Mouse Movement

Eastshade explains that the player can click characters or interactable targets, but this does not mean you can freely control character movement with the mouse alone. First check the remappable keys in the current settings.

## Check Music Controls

Music input may require extra keys or timing actions. If you want to reduce keyboard use, check the in-game music help and current keybinds; the original page did not guarantee that all actions can be done with the mouse alone.
