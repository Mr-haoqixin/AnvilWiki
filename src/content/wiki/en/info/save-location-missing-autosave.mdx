## Check the Correct Windows User

Confirm that the currently logged-in account is the Windows account used when playing the demo. The save directory from Eastshade docs is:

`%USERPROFILE%\AppData\LocalLow\Eastshade Studios\Songs of Glimmerwick`

Enter this path in the File Explorer address bar, and Windows will auto-replace the current user directory. If you played on another account, check the path for that account.

## Protect Save Files

The original page recorded that a player found `Player`, `Player-prev`, and `steam_autocloud.vdf`, but after copying the files, progress still could not be loaded. Therefore, finding the files does not mean recovery is verified; copy a backup before trying any changes, and keep the original files.
