## Confirm the Character Name Before Typing

Demo controller players have reported that the input box labeled as save file name ended up as the character name. When creating, type the name you want the character to use and check the on-screen prompt, to avoid using a temporary number as the name.

## witch Is a Universal In-Game Title

Eastshade clarified on 2026-09-27 that the **witch** title in the game also applies to male characters. Seeing this word alone does not mean your appearance choices did not take effect.
