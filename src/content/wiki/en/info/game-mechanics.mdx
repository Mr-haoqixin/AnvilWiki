## Time & Calendar

| Parameter | Value |
| --- | --- |
| 1 in-game hour | 75 seconds |
| 1 in-game day | ~30 minutes |
| 1 season | 14 days |
| 1 year | 56 days (4 seasons × 14) |
| Wake up | 06:00 |
| New game starts | 07:12 |
| Night freeze | 22:00–05:17 |
| Auto-save | 12:00 |

**No time pressure**: Clock freezes at night and during calendar events. After Year 1 Winter, eternal spring begins. No exhaustion — v1.06 has no mechanism that forces your day to end.

## Weather

Weather is **not random**: the game follows a fixed 56-day schedule. 12 rain days, 10 snow days (6 heavy), 24 fog days. Rain/snow auto-waters all crops.

| Season | Rain/Snow days |
| --- | --- |
| Spring | 5, 9, 12 |
| Summer | 4, 12 |
| Autumn | 2, 4, 6, 7, 8, 11, 12 |
| Winter | 1, 2, 3, 4, 5, 7, 8, 9, 10, 12 (snow) |

## Mana

| Parameter | Value |
| --- | --- |
| Initial cap | 350 |
| Maximum cap | 1,000 |
| Recovery | Fully restores each morning |
| Food recovery | 65% of base value (herbs half; +7 if below 21) |

### Raising Mana Cap

- **Mana Enrichment** ×3: +100 each
- **Desolation Dirge**: +50 per shrine destroyed
- **Moonstone** (shed ghost quest reward): +150

## XP & Levels

Every 11 XP grants 1 level and 1 skill point. Level = XP ÷ 11 (floor) + 1. Unlocking all 31 abilities requires 341 XP (level 32).

### XP Sources

| Source | XP |
| --- | --- |
| Complete quest (minor/major) | 3/5 |
| Attend class | 2 |
| Learn/perfect song (first time) | 1/1 |
| Potion recipe new quality tier | 1 |
| Restore shrine | 2 |
| Summer Music Festival (perfect/otherwise) | 5/3 |
| Camping trip | 3 |

## Selling & End-of-Day Scroll

No shops buy items — everything sells through the **Magic Well**. Payment is received when sleeping, itemized on the end-of-day scroll. Sell prices are identical everywhere.

| Bonus | Source | Effect |
| --- | --- | --- |
| Gardening bonus | Farm Merchant | +10% |
| Fishing bonus | Fishmonger | +20% |
| Baking bonus | Esteemed Baker | +40% |

## Assist Options (3 sliders)

In Options → Game, three sliders make mini-games easier, each with 4 levels.

| Option | None | Slight | Extra | Extra Double |
| --- | --- | --- | --- | --- |
| Potion Mastery Help | 100% | 80% | 60% | 40% |
| Song Mastery Help | 100% | 75% | 50% | 25% |
| Fishing Help | +0% | +30% | +60% | +90% |
