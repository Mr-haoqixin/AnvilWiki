## Crafting System

- **44** recipes
- **4** carpentry levels (from ability tree)
- **17** recipes sold in shops

## Profit & Loss Analysis

**Profitable recipes** (sell price > ingredient cost):

| Recipe | Margin |
| --- | --- |
| Ornate Trellis | **+40** |
| Garden Lantern (all level 3 variants) | **+15** ×8 |
| Garden Lantern (level 2) | **+5** |
| Garden Lantern Cottage | **+5** |
| Technical Challenge Trophy | **+5** |

**Loss-making recipes** (sell price < ingredient cost):

| Recipe | Loss |
| --- | --- |
| Fountain | **-55** |
| Carved Bench / Driftwood Bench / Metal Bench / Painted White Bench | **-45** |
| Lantern | **-35** |
| Chest | **-35** |
| Stone Trellis | **-30** |
| Stone Garden Lantern | **-16** |
| Merfolk Trellis | **-15** |
| Cart | **-20** |
| Log Bench / Wood Bench | **-5** |
| Shears | **-5** |
| Stone Path | **-3** |

Ingredient cost uses the cheapest shop price for each ingredient; "≥" means some ingredients can't be bought. Margin = sell price − ingredient cost.

## Learn Sources

- **Practical Practice** (The Cup & Kettle, Tue/Thu/Fri/Sun): Chest, Cushion, Stone Path, Carved Bench, Garden Lantern, Lantern, Trellis, Wheatmill, Beehive, all Garden Lantern variants, Fountain
- **NPC teachers**: Chicory (habitat recipes), Professor Rohesia (Shears), Florian (Carved Bench, Garden Lantern Brass)
- **Festival shops**: Gwen (Pumpkin Moon Festival — Stone Bench, Stone Garden Lantern, Stone Trellis), Goods Shopkeeper (Seaflower Festival — Merfolk series)
- **Other**: Fairy royalty (Vested Pack Owl Habitat), Dorm Hall schematic (Garden Lantern Snail), conversation (Stone Path, Garden Lantern)
