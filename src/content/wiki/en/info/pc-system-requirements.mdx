## Minimum Requirements Recorded on the Source Page

The original page recorded the Steam minimum specs on 2026-09-28: **6 GB RAM**, **5 GB** free space, a 64-bit dual-core processor, and an older GPU supporting Shader Model 3.0. The 3 GB RAM in old search results is outdated, and specs may continue to update.

## Do Not Misread the Windows Field

The store game field shows Windows 7 64-bit, but the Steam client indicates support for Windows 10 and newer. This game field should not be read as recommending installing the current Steam client on Windows 7.
