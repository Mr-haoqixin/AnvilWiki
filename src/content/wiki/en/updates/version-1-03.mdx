## Quests, Characters & Activities

- Fixed **Vivian** and mud pie quest related issues, and **Acorn** not appearing during **Celia**'s prank event.
- Fixed issues from delivering toadstool first and moving pet habitat before pet arrival; for saves that already encountered the issue, the pet now arrives the next day.
- Fixed **Seaflower Festival** dive point only being interactable via spacebar, and corrected a flower festival achievement.
- **Nocturne Forest** picnic now allows submitting multiple of the same snack.

## Items, Gameplay & UI

- **Kavita** now sells watering cans, for players who accidentally dropped their can into the well.
- Adjustment note: songs without a practice version that only need a short play (e.g., **Alchemical Resonance**) now note this in the UI.
- Feathers no longer used in mushroom dough; lowered **Apple Toss** win threshold.
- Added slow-use mode for Scythe: hover the item over grass; the official recommendation is still to equip and press spacebar.
- Quickbar cycling hint icons now respect some custom key bindings; fixed binding issues when holding Shift to input special characters (e.g., `@`).
- Fixed several missing translations.
