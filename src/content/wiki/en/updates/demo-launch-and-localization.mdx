## Public Demo Launch — 2026-04-07

Eastshade announced the public demo launch and invited players to submit feedback via the feedback form, Discord, or email. The announcement stated the demo would be used to collect feedback and improve the game before the 1.0 full release; it also previewed upcoming work on the tailor shop **Swish and Stitch** soft lock, default key bindings for different keyboard layouts, and multilingual support.

[Official Demo Launch Announcement](https://steamcommunity.com/games/1706510/announcements/detail/1828894815568107)

## Localization Update — 2026-05-12

Eastshade subsequently released a demo localization update. The announcement listed added languages including Simplified Chinese, German, Russian, European Spanish, Brazilian Portuguese, French, and Japanese; language support should be verified against the current Steam page.
