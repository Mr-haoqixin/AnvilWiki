## Demo Version 0.484 — 2026-06-13

- Lowered difficulty of the first song **Song of Tilling**, improving the music minigame difficulty curve.
- Fixed some language text in the game map legend, and a watering can-related soft lock near the player's pond.
- Developer reiterated: the music minigame is not required to cast songs; proficiency takes multiple attempts, and you are not expected to reach the highest rating on the first or fourth try.

[Official 0.484 Announcement](https://steamcommunity.com/games/1706510/announcements/detail/1835236783566225)

## Demo Version 0.466 — 2026-04-14

- This version was re-released; the official notes said 0.465 changes are also included.
- Added several clock mechanic tutorials.
- Added an additional help layer for the music minigame in options.
- Reiterated that casting songs does not require earning stars in the music minigame.

[Official 0.466 Announcement](https://steamcommunity.com/games/1706510/announcements/detail/1829528821316686)

## Demo Version 0.465 — 2026-04-11

- Added default key bindings for common regional keyboards; the first update may override some players' custom mappings.
- Keyboard & mouse mode uses **M** to open the map; controller uses right stick click.
- Adjusted difficulty for learned star and perfected star ratings; fixed music class return key icon.
- **Escape** can exit menus, close readable text, and close player menus.
- Fixed soft locks from sitting in chairs, saving in water, entering the potion classroom too early, and entering the potion class after already putting down a cauldron.
- Console key changed to **Home**; PlayStation controller support is still in development, some icons may be incorrect.

[Official 0.465 Announcement](https://steamcommunity.com/games/1706510/announcements/detail/1829528821312785)

## Demo Version 0.464 — 2026-04-09

- Opening the player menu or shop now pauses the clock; entering flute mode still continues the timer, by design.
- If you need to pause time to practice songs, go to the practice rooms in the music classroom.
- Fixed `=+` markers appearing before some NPC dialogue options.
