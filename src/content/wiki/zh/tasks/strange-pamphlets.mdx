## 任务概要

**奇怪的小册子**是《格林默威克之歌》44个任务之一。

| 属性 | 内容 |
| --- | --- |
| 发布者 | 阿比盖莉娅校长 |
| 步骤数 | 6 |
| 经验值 | 5 |
| 奖励 | 100 金花瓣、300 金花瓣 |

## 攻略步骤

| 步骤 | 目标 |
| --- | --- |
| 1 | 在 校长办公室 与 阿比盖莉娅校长 交谈。 在 大礼堂 与 弗恩 交谈（14:25 起）。 |
| 2 | 在 灰厅 与 罗文 交谈。 |
| 3 | 弗恩在调查如何解决嘈音诅咒。目前我做不了什么。 |
| 4 | 校长得知嘈音诅咒后似乎很不安。目前我做不了什么。 |
| 5 | 在 大礼堂 与 弗恩 交谈（14:25 起）。 在 校长办公室 与 阿比盖莉娅校长 交谈。 |
| 6 | 诅咒解除，任务完成。 |
