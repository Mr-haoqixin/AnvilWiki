## 秋季目标总览

秋季是**集中收获和交易**的季节。核心目标是**推进咸水澡堂任务线、完成古代神龛、解谜问询洞窟、处理诅咒任务**。秋季结束解锁**秋季**成就。

## 阶段一：咸水澡堂任务线

秋季核心任务线在[咸水澡堂](/zh/locations/briny-bathhouse/)展开：

1. 进入咸水澡堂与相关 NPC 对话
2. 推进浴场相关任务，详见[咸水澡堂种子不生长](/zh/tasks/briny-bathhouse-seed-not-growing/)
3. 获取浴场经验与水系装备，详见[浴场经验与水系装备](/zh/tasks/bathhouse-xp-water-wear/)

## 阶段二：古代神龛推进

### 第七座神殿

古代神龛任务在秋季关键推进：

1. 向人类学家报告神殿进度
2. 若古老神殿仍显示进行中，检查寺庙中的**第七座神殿**成就
3. 详见[古老神殿仍显示进行中](/zh/tasks/ancient-shrines-quest-completion/)

### 秋季鲑鱼

秋季专属线索：在猫头鹰旁的河流寻找鲑鱼。鲑鱼是神龛任务的关键道具，其他季节可能没有。

- 详见[夜曲森林神殿位置](/zh/tasks/nocturne-forest-shrine-location/)
- 钓鱼方法见[钓鱼入门](/zh/tasks/fishing-rod-how-to-fish/)

## 阶段三：问询洞窟

问询洞窟是秋季解谜任务：

1. 解谜盒子，慢慢答
2. 详见[长笛问答选项](/zh/tasks/flute-quiz-choices/)
3. 问询洞窟成就首发周解锁率约 3%

## 阶段四：诅咒相关任务

秋季推进诅咒相关任务线：

1. **[妮莎](/zh/characters/nessa/)的诅咒**：妮莎友情线的诅咒处理（首发周 3%）
2. **去蓝茶**：治疗蓝脸症，详见[悲孢蓝脸状态：去蓝茶解法](/zh/tasks/blueface-debluing-tea/)
3. **沉默印刷机**：产出嘈杂碎片，与弗恩对峙相关

## 阶段五：收获与交易

秋季是经济活动密度最高的季节：

- 把前两季的投入转化为资金和资源储备
- 为过冬和来年开局做准备
- 出售物品见[在花园井出售物品](/zh/tasks/sell-items-gold-petals/)
- 详见[季节规划：四季循环与年度节奏](/zh/info/seasonal-guide/)

## 秋季可错过事件提醒

- 秋季鲑鱼是季节限定，错过需等下一年
- 神龛任务需在秋季推进第七座
- 详见[限时活动会错过吗？](/zh/tasks/missable-events-time/)

## 秋季结束检查清单

完成以下内容后秋季即可结束：

- [x] 推进咸水澡堂任务线
- [x] 完成第七座神殿
- [x] 秋季鲑鱼获取并交付
- [x] 问询洞窟解谜完成
- [x] 处理妮莎诅咒相关任务
- [x] 秋季收获与交易回笼资金
