## 春季目标总览

春季是第一年开局阶段，核心目标是**完成入学、解锁基础魔法、开辟种植区域**。这一季把"学歌"和"开地"两件事跑通，为后续高产出打地基。春季结束时解锁**春季**成就（首发周解锁率 14%）。

## 阶段一：序章与入学

### 从盐风海岸到蚀刻学院

完整序章流程见[序章完整攻略](/zh/tasks/prologue-walkthrough/)。简要步骤：

1. 创建角色后乘船抵达[盐风海岸](/zh/locations/saltwind-coast/)，找到[阿比盖莉娅](/zh/characters/abigailia/)获取入学信
2. 前往南方找制笛师[布里斯科恩](/zh/characters/bristlecone/)，先收集学校用品再取[长笛](/zh/items/flute/)
3. 进入[威斯克](/zh/locations/wisk/)镇采购五件用品：长笛、长袍、[坩埚](/zh/items/cauldron/)、药水入门套装、技能饰品
4. 参加入学典礼，解锁**入学**成就（首发周 84%）

详见[入学第一天：领取用品并找到宿舍](/zh/tasks/first-day-school-supplies/)。

### 克拉丽院长与植物园

入学后跟随[克拉丽院长](/zh/characters/dean-clary/)完成植物园首次种植：

1. 学习挖地法术，种罗勒种子，用浇水壶浇水
2. 完成后获得伐木法术
3. 详见[找到克拉丽院长与植物园](/zh/tasks/find-dean-clary-garden/)

### 室友与音乐史课

周二遇到室友[克洛弗](/zh/characters/clover/)。[琳内亚教授](/zh/characters/linnea/)的音乐史课提供镐法术，详见[琳内亚教授：音乐史教授与镐法术](/zh/characters/linnea/)。

## 阶段二：海花节花赛

春季核心节日是**海花节**（Seaflower Festival）。赢下花赛解锁成就（首发周 13%）。准备工作：

- 提前种植花卉品种，确保花赛当日有足够花朵参赛
- 关注花赛的具体评判标准（品种、数量、排列）
- 花赛是春季限定活动，错过需等下一年

详见[季节规划：四季循环与年度节奏](/zh/info/seasonal-guide/)。

## 阶段三：克洛弗郁金香任务线

春季推荐优先推进[克洛弗](/zh/characters/clover/)的友情线：

1. 与克洛弗对话触发郁金香任务
2. 凑够郁金香交付，解锁**生意伙伴**成就（首发周 25%）
3. 郁金香和羊毛这类任务只从对话触发，第一个游戏周应与所有人说话

攻略建议**一次推进一条友情线**，克洛弗是推荐优先项之一。

## 阶段四：妖地之歌练习

春季课程涵盖基础歌曲学习。妖地之歌是核心法术之一：

- 通过课程学习音符与旋律组合
- 不同歌曲协助钓鱼、园艺和探索等日常活动
- 详见[歌曲精通辅助是什么意思？](/zh/tasks/song-mastery-help/)

## 春季可错过事件提醒

开发者说明故事活动不会因时钟前进而过期，但 NPC 和商店仍有日程。关键提醒：

- 海花节花赛是季节限定，错过等下一年
- NPC 夜间可能不可互动，白天再尝试
- 详见[限时活动会错过吗？](/zh/tasks/missable-events-time/)

## 春季结束检查清单

完成以下内容后春季即可结束：

- [x] 入学蚀刻学院，解锁入学成就
- [x] 完成植物园首次种植，获得伐木法术
- [x] 参加海花节花赛
- [x] 推进克洛弗郁金香任务线（生意伙伴）
- [x] 学习基础歌曲与妖地之歌
- [x] 与所有镇民对话，触发可用任务
