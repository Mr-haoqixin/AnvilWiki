## 版本 1.09 更新了什么？

版本 1.09 主要是问题修复，重点涉及任务与角色出现条件，也改善了物品说明和控制器输入。

| 类别 | 更新内容 |
|------|----------|
| 任务与角色 | 修复秋季同学缺席；若在盗窃事件后完成[弗恩的对质](/zh/tasks/ferns-confrontation/)，[六弦竖琴](/zh/tasks/harp-of-six/)任务中的西妮娅可能缺席；修复妮莎在树屋时缺少泥饼配送选项。 |
| 活动冲突 | 修复弗恩的对质与[海花节](/zh/locations/seaflower-festival/)之间的冲突。 |
| 物品与交付 | 修复容器物品说明闪烁、无尽书页重复获得和交付道歉蠕虫的问题。 |
| 操作 | 修复在手柄与键鼠之间切换时的钓鱼问题。 |
| 其他 | 支持者包 MP3 新增安托万的歌曲，并修正 Steam Deck 上的大部分字形显示问题。 |
