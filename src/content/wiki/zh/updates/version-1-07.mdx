## 版本 1.07 新增了哪些内容？

版本 1.07 为鼠标键盘操作新增快速转移功能，附带涵盖堆叠拆分的教程弹窗，并为背包与容器加入整理功能；巫火草也悄悄进入了某家商店的货架。

| 功能 | 说明 |
|------|------|
| 快速转移 | 按住 **Shift** 并右键点击物品，即可在背包与打开的容器之间移动物品。 |
| 教程弹窗 | 首次使用时弹出简短教程，其中包含堆叠拆分的方法。 |
| 整理功能 | 玩家背包与容器均新增整理（排序）功能。 |
| 商店进货 | 巫火草现在可以在某家商店购买；官方公告为避免剧透未指明是哪一家。 |

试玩版时期的键盘拆分堆叠习惯，可参考[拆分物品堆叠：试玩版键盘操作](/zh/tasks/split-item-stacks/)。

## 版本 1.07 修复了哪些问题？

本次更新修复了二十余个问题，涵盖任务软锁、日程与对话异常、经济漏洞以及场景细节，主要包括：

**任务与剧情**

- 修复[科德里恩](/zh/characters/codrin/)任务中醒来时的镜头问题。
- 修复[克洛弗](/zh/characters/clover/)生病期间被锁在宿舍内的问题。
- 修复[西莉亚](/zh/characters/celia/)恶作剧的软锁（与[阿科恩](/zh/characters/acorn/)的任务冲突导致）。
- 修复[克洛弗的困境](/zh/tasks/clovers-calamity/)集市日之后[弗洛里安](/zh/characters/florian/)日程回退的问题。
- 当[玛丽](/zh/characters/mary/)在草药植物学课上时，玩家角色在八卦圈活动中也有了自己的反应台词。
- [皮耶特](/zh/characters/pieter/)的对话现在会正确检查与[诺拉](/zh/characters/nora/)相关话题的时间条件。

**经济与漏洞**

- 修复疯狂点击日结算收入画面即可跳过天数的问题。
- 修复[磨坊面粉任务](/zh/tasks/flour-wheatmill-cursed-mill/)中磨坊主免费给面粉的问题。
- 修复蓝莓种子导致的无限金钱漏洞。
- 修复克洛弗重复出现的两种情况（期末考试期间与地板冲突所致），并修正相关的堆叠上限。

**场景、物品与操作**

- 物品信息卡不再显示调试文本。
- 快速转移现在会拒绝不可丢弃的物品。
- 修复[梅尔和卢西娜的贝壳屋](/zh/locations/mel-and-lucinas-shell/)附近的碰撞空洞。
- 改进了逃生绳放置位置的保护，详见[夜曲森林快速旅行绳索](/zh/tasks/nocturne-forest-fast-travel-rope/)。
- 在获得宠物之前，现在也可以移动宠物栖息地（见[宠物驯服指南](/zh/info/pets-overview/)）。
- 修复[掷苹果](/zh/locations/apple-toss-minigame/)小游戏中的音乐中断问题。
- 修复手柄按键提示的问题。
- 游戏内漏洞反馈工具在输入长文本时不再崩溃。

## 版本 1.07 在 Steam Deck 上有变化吗？

有——Steam Deck 上的界面与文字更大，这是为通过 Steam Deck 验证所做的准备。当前兼容状态与注意事项详见 [Steam Deck 兼容性与操作注意事项](/zh/info/steam-deck-compatibility/)。
