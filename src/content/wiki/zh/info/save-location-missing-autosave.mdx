## 检查正确的 Windows 用户

确认当前登录的是游玩试玩版时使用的 Windows 账户。Eastshade 文档给出的存档目录为：

`%USERPROFILE%\AppData\LocalLow\Eastshade Studios\格林默威克之歌（Songs of Glimmerwick）`

在文件资源管理器地址栏输入该路径，可由 Windows 自动替换当前用户目录。若使用另一个账户游玩，应检查那个账户对应的路径。

## 保护存档文件

原页记录玩家找到 `Player`、`Player-prev` 与 `steam_autocloud.vdf`，但复制文件后进度仍未能载入。因此，找到文件不等于已经验证可恢复；尝试任何更改前先复制备份，并保留原文件。
