## 时间与日历

| 参数 | 值 |
| --- | --- |
| 游戏内 1 小时 | 75 秒 |
| 游戏内 1 天 | 约 30 分钟 |
| 一季 | 14 天 |
| 一年 | 56 天（四季×14） |
| 起床时间 | 06:00 |
| 新游戏开始 | 07:12 |
| 夜间冻结 | 22:00–05:17 |
| 自动存档 | 12:00 |

**没有时间压力**：夜间和日历活动期间时钟都会冻结。第一年冬季结束后进入永恒春天。不会累倒——1.06 版没有任何机制强制结束一天。

## 天气

天气**并非随机**：游戏遵循固定的 56 天日程。共 12 个雨天、10 个雪天（6 天大雪）、24 个雾天。雨雪自动浇灌所有作物。

| 季节 | 雨/雪天 |
| --- | --- |
| 春季 | 5, 9, 12 |
| 夏季 | 4, 12 |
| 秋季 | 2, 4, 6, 7, 8, 11, 12 |
| 冬季 | 1, 2, 3, 4, 5, 7, 8, 9, 10, 12（雪） |

## 法力

| 参数 | 值 |
| --- | --- |
| 初始上限 | 350 |
| 最高上限 | 1,000 |
| 恢复 | 每天早上完全恢复 |
| 食物恢复 | 基础价值 65%（草药减半；低于 21 时 +7） |

### 提升法力上限

- **法力充盈** ×3：每次 +100
- **荒芜挽歌**：每摧毁一座神龛 +50
- **月光石**（花园小屋幽灵任务奖励）：+150

## 经验与等级

每 11 经验升 1 级并获得 1 技能点。等级 = 经验 ÷ 11（向下取整）+ 1。解锁全部 31 个能力需 341 经验（等级 32）。

### 经验来源

| 来源 | 经验 |
| --- | --- |
| 完成任务（小/大） | 3/5 |
| 上课 | 2 |
| 学会/精通歌曲（首次） | 1/1 |
| 药水配方达新品质档 | 1 |
| 修复神龛 | 2 |
| 夏日音乐节（完美/否则） | 5/3 |
| 露营之旅 | 3 |

## 出售与日终卷轴

没有收购物品的商店——一切通过**魔法井**出售。睡觉时按价值付款，日终卷轴逐项列出。售价在任何地方都相同。

| 加成 | 来源 | 效果 |
| --- | --- | --- |
| 园艺加成 | 农场商人 | +10% |
| 钓鱼加成 | 鱼贩 | +20% |
| 烘焙加成 | 杰出面包师 | +40% |

## 辅助选项（3 个滑块）

在「选项 → 游戏」中有三个让小游戏更容易的滑块，各有四档。

| 选项 | 无 | 轻微 | 额外 | 额外双倍 |
| --- | --- | --- | --- | --- |
| 药水精通帮助 | 100% | 80% | 60% | 40% |
| 歌曲精通帮助 | 100% | 75% | 50% | 25% |
| 钓鱼帮助 | +0% | +30% | +60% | +90% |
