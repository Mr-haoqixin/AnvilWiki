## Étapes de jeu manuel

1. Ouvrez le menu et fixez **Song of Silence**.
2. Tenez-vous près du moulin, appuyez sur **R** pour entrer en mode instrument.
3. Jouez les notes affichées à l'écran pour la chanson fixée.

## Explication des touches

La séquence clavier apparue dans la discussion est `d、k、f、;、l`, valable uniquement pour la configuration clavier correspondante. Ne la traitez pas comme une table de touches manette ; la page source enregistre un signalement joueur, pas un mapping unifié pour tous les périphériques.
