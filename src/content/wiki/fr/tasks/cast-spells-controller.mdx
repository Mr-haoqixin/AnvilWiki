## Séquence de lancement signalée par le joueur

Dans le spell book, sélectionnez la chanson à utiliser, appuyez sur **X** pour la fixer ; appuyez sur **RT** pour commencer l'invite instrument, puis sur **A** pour consommer le mana, et enfin sur **X** pour terminer le jeu.

## Ne pas traiter comme une table de touches universelle

Cette combinaison de touches provient d'un signalement de joueur en démo, pas d'une description officielle pour toutes les dispositions de manette. Si le jeu affiche des indications différentes, priorisez les réglages de votre périphérique et de vos contrôles personnalisés.
